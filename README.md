## 🎮 O que é isso?

**FC-Mod-Manager-BR** é uma ferramenta completa de gerenciamento de mods para **EA Sports FC 26, FC 25, FC 24** e todos os jogos **FIFA do 19 ao 23**. Suporta arquivos .fifamod e .fbmod, oferecendo importação por arrastar e soltar, controle de ordem de carregamento, detecção de conflitos e integração com BepInEx. Perfeito para melhorar gráficos, kits, rostos, estádios, jogabilidade e o Modo Carreira.

## ✨ Funcionalidades

- **Importação Arrastar e Soltar** – Adicione arquivos .fifamod e .fbmod instantaneamente
- **Controle de Ordem de Carregamento** – Organize mods para evitar conflitos
- **Detecção de Conflitos** – Detecta automaticamente arquivos sobrepostos
- **Pontos de Restauração** – Reverta para estados anteriores com um clique
- **Navegador da Loja de Mods** – Navegue e instale mods de repositórios confiáveis
- **Gerenciador BepInEx** – Instalação e configuração do BepInEx com um clique
- **Carregador de Presets** – Carregue presets de mods reutilizáveis facilmente
- **Gerenciamento de Perfis** – Salve e carregue diferentes configurações de mods
- **Integração com Editor Ao Vivo** – Edição de memória em tempo real para o Modo Carreira
- **Editor de Jogadores** – Edite atributos, aparência, estilos de jogo
- **Editor de Times** – Edite tabela da liga, orçamento de transferências, formação, time titular
- **Editor de Banco de Dados** – API LUA para interação programática

## ⚙️ Instalação

1. Clique no botão de download acima
2. Extraia o arquivo
3. Execute `FC-Mod-Manager-BR.exe` como Administrador
4. Selecione seu jogo (FC 26/25/24 ou FIFA 19-23)
5. Arraste e solte seus mods ou navegue pela Loja de Mods
6. Clique em Aplicar e inicie o jogo

## 🐛 Solução de Problemas

| Problema | Solução |
|----------|---------|
| O gerenciador de mods não funciona | Execute como Administrador, desative o antivírus temporariamente |
| Mods não carregam no jogo | Verifique a ordem de carregamento, certifique-se de que os mods são compatíveis, verifique se os arquivos .fifamod não estão corrompidos |
| O jogo trava com mods | Tente desativar os mods um por um, use o ponto de restauração para reverter alterações, verifique conflitos entre mods |
| O anti-cheat (EAAC) bloqueia mods | Use o modo offline para mods single-player, remova os mods antes de ficar online |
